# Task 4: PyBot - Basic GUI Chatbot 🤖

A modern, interactive rule-based Python chatbot featuring a Graphical User Interface (GUI), developed for the **CodeAlpha Python Programming Internship**.

---

## 📌 Project Overview
PyBot is a desktop application built with Python's Tkinter framework. It features user authentication, custom chat bubble UI, dynamic light/dark theme switching, built-in math expression solving, and responsive threaded execution.

---

## ✨ Features
* **User Authentication:** Login and registration interface with user session tracking.
* **Modern Tkinter GUI:** Custom chat bubbles, scrollable view, and clean visual layout.
* **Dynamic Dark/Light Theme:** Smooth toggling between Light and Dark visual modes.
* **Math Expression Solver:** Automatically solves mathematical calculations (e.g., `25 * 4`).
* **Quick Reply Pills:** Interactive preset buttons for common prompts (`hello`, `time`, `joke`, `help`).
* **Threaded Response Handling:** Uses Python's `threading` module to keep the GUI fluid and responsive.

---

## 🧠 Concepts Applied
* Object-Oriented Programming (OOP with custom Tkinter Frame routing)
* `tkinter` & `ttk` (GUI layouts, canvas controls, and event handling)
* `threading` (Asynchronous UI operations)
* String manipulation and safe evaluation logic
